Portable · Windows 11 64-bit · nothing to install

Less light around you, more focus on the game

No digging through monitor menus mid-match: Penumbra handles it for you.

  • Automatic game mode

    Detects a fullscreen app on your main monitor and applies your preset within seconds.

  • Real monitor brightness

    Changes brightness over DDC/CI, right on the monitor, instead of just laying a dark overlay on top.

  • Each monitor your way

    In each preset, choose to keep, set a brightness for or turn off every secondary monitor.

  • Comes back by itself

    When you leave the game, each monitor returns to the default brightness you set on the widget’s cards.

  • Glass widget

    Borderless and draggable, with + and − buttons for each monitor. It hides away in the Windows tray.

  • Open source

    Open code on GitHub. No ads, no account and no data collection.

How it works

Set it up once and forget about it.

  1. Download and open

    If Windows warns you, click More info → Run anyway. The widget appears on screen.

  2. Build your preset

    Star your main monitor and choose what happens to each secondary one during games.

  3. Play

    Open your game in fullscreen. Secondary monitors dim by themselves and return to normal when it closes.

Frequently asked questions

Do I need to install Penumbra?

No. It’s a single Penumbra.exe with everything built in, including .NET. Just download and open it. It doesn’t ask for administrator rights.

Is my monitor compatible?

It needs to support DDC/CI, which is common on external monitors and sometimes has to be enabled in the monitor’s own menu. Laptop screens, some adapters and some docks don’t offer this control. When there’s no response, the card shows N/D.

Windows said “Windows protected your PC”. Is it safe?

This SmartScreen warning appears for new programs without a digital signature yet. Penumbra’s code is open and the executable is built automatically on GitHub from it, with a SHA-256 hash published for each release. Click More info → Run anyway.

Does it touch my game?

No. Penumbra only checks whether the active window covers the main monitor. It doesn’t inject anything into the game or read its memory.

Does fullscreen video trigger game mode too?

Yes, because detection is based on fullscreen. To watch without triggering it, use Pausar detecção (pause detection) in the tray icon menu.

What if I choose “Desligar” (turn off)?

Some monitors only come back with their physical button, or make Windows move your open windows. If that happens with yours, use 0% brightness in the preset.

How do I close Penumbra?

The widget’s X only hides it. To quit, right-click the tray icon and choose Sair (exit).
